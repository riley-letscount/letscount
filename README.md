# 同じ所を2度通らない道順の数

n×n のマス目で、左上のスタートから右下のゴールまで、同じマスを二度通らずにたどる道順の数を数えるプログラムです。アニメ『フカシギの数え方』に登場する「おねえさんのコンピュータ」を題材に、[shogo82148](https://shogo82148.github.io/letscount/) さんの実装を見て組んだものです。元ネタの動画は『[フカシギの数え方』おねえさんといっしょ！みんなで数えてみよう！](https://www.youtube.com/watch?v=Q4gTV4r0zRs)』です。

## 使い方

- ブラウザでページを開き、シングル／マルチを選んでからマス目の大きさを選ぶと計算が始まります
- シングル: 1コアだけで計算します。シングルコア性能が高い端末（iPhoneなど）で速い方法です
- マルチ: 複数のコアを並列に使います。コア数の多いデスクトップPC向けです。「自動」はブラウザが報告する論理コア数（上限128）を使います。端末によってはブラウザがコア数を小さく丸めて報告する場合があるため、表示が実際の論理コア数と違うときは手動で変更してください
- マス目は 20×20 まで選べます。17×17 以上はメモリを大量に使うので注意してください（スマートフォンではほぼ確実にメモリ不足で落ちます。終わる保証はありません）
- 経路数は 万・億・兆・京… の単位表記で表示されます（正確な全桁も併記されます）

## ローカル版（Windows用 / Mac用）

ページ下部のカードから、ローカル版をダウンロードできます。Web版と同じ内容・構成（シングル／マルチ選択、ハッシュ方式のみ、20×20まで）です。

- Windows用: letscount-ui.exe（WebView2ランタイムが必要。Windows 11には標準搭載）。未署名の実行ファイルのため、スマートアプリコントロール等でブロックされる場合があります
- Mac用: おねえさんのコンピュータ.app（zip形式、Apple Silicon用）。zipを展開して起動してください。未署名のため、初回は右クリック→「開く」が必要な場合があります

## 既知の値について

ページ内の既知値テーブルは計算結果の照合専用です。答えは毎回その場で計算しています。

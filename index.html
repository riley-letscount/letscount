マス目の大きさ
20×20 は状態数が 16×16 からさらに桁違いに増え、数十GB級のメモリが必要になる可能性が高く、通常のPCでも完走は困難です。スマートフォンではほぼ確実にメモリ不足で落ちます。終わる保証はありません（時間もメモリも未知数です）。開始はできますが、止めるときは「停止」ボタンを押してください（停止時点の数字は未確定です）。

「教えてあげる」とマルチの中身 — なぜ速いのか

高速モードは、ZDD そのものを全部構築するのではなく、Simpath（frontier 法）で 「ZDD のノード共有と等価なメモ化」を行う実装です。シングル／マルチとも状態の表し方と遷移規則は パック方式で共通です。速度の本体は次の工夫です。

  • frontier（境界）を小さく保つ：辺を行優先（上から下、左から右）に1本ずつ処理すると、処理済みと未処理の両方に触れている点は最大でも n+1 個程度しかありません。覚えるべき状態はこの境界分だけです。
  • mate（端点ペアリング）の共有：frontier 上の各点について、処理済みの辺でできた部分経路の「端点同士のつながり（mate）」を状態にします。同じ mate 状態に到達した部分探索は1つに合流し、経路数を BigInt で合算します。これが組み合わせ爆発を抑えます。状態の Map は辺 1 本分のレイヤごとに作り替え、不要になった世代は解放します。
  • パック方式（2bitパック）：状態を「単一の数値キー → 件数（BigInt）」だけで保持し、遷移はキーに対するビット演算（プラグ符号の抽出、括弧の対応付け、フィールドの書き換え）で完結させます。キーは、プラグ符号を1セル2bit（0=プラグなし、1=開き括弧、2=閉じ括弧、3=X）に詰めた部分と、次数2のセルを示す1セル1bitの印を、同じ整数に収めたものです。始点につながる端点プラグと終点につながる端点プラグはどちらも同じ記号 X で表します。終点側のプラグは「終点セル自身の括弧の相手」として判別でき、始点側のプラグは常にその左に現れるため、この統合で異なる状態が衝突することはありません。Xと括弧プラグの接続では端点側が部分経路を吸収して結果も X になり、X同士の接続は始点側と終点側の接続（経路の完成）に対応します。16×16以下ではキーは安全整数（Number）に収まりますが、17×17以上では溢れるため、同じ詰め方のままキーだけを BigInt に切り替えます（詰め方・遷移規則は同一です）。
  • マルチ（シャーディング）：マルチモードでは、次レイヤの状態表をキーのハッシュで Worker 数ぶんのシャードに分割し、各 Worker が自分のシャードだけを保持・合流します。どの Worker も全体を計算し直すことはないので、並列化しても総作業量は増えません。各 Worker は生成した（キー, 件数）を宛先シャードごとに仕分けて型付き配列に詰め、メインスレッド経由で転送します（件数は基数1e9の肢に分解して載せます）。メインスレッドは中継とバリア同期だけで、合流計算はしません。状態数が少ない序盤のレイヤでは、転送の無駄を避けるため Worker 1台だけで処理し、大きくなった時点でシャードへ分配します。合流はこのシャーディング＋Map 合流のみで、ソート方式は使っていません。
  • 対称性：最初の一手は右か下しかなく、転置対称で両方の経路数は等しくなります。右に固定して数え、最後に2倍します。
  • 枝刈り：ゴールに到達した経路はそれ以上伸ばさない／次数が2を超える辺・始点と終点の次数1を超える辺は入れない／部分経路の両端を結んで閉路になる接続は捨てる／frontier から外れる点に端点（次数1）が残っていたら行き止まりとして打ち切ります。
  • 環境による差：マルチの効果はコア数とブラウザ次第です。コアの少ない端末や iPhone では、転送と合流の分だけシングルより遅くなる場合があります。マルチはコア数の多いデスクトップ（特に Windows）での利用を想定しています。
  • 表示の軽量化：通常モードの経路描画は約90msごと、高速モードの進捗報告は250msごとに間引きます。大きな数は桁区切り＋桁数で表示します。

通常モードは素朴な深さ優先探索で経路を1本ずつ数えるため、サイズが大きくなると組み合わせ爆発で 事実上終わらなくなります。その差を比べるのがこのプログラムの狙いです。

GUI版（ローカル実行用）

このページと同じ構成の GUI アプリです。ダウンロードしてローカルで実行できます。 最初にシングル／マルチを選びます。シングルはスレッド1固定、マルチはスレッド数の「自動」（端末の実際の論理コア数、上限128）が初期値で、手動選択もできます。 合流方式はハッシュ（シャーディング）のみ、サイズは 1×1〜20×20 対応で、17×17以上ではメモリ大量使用の警告を表示します。 ブラウザの制限を受けず、CPUコアをそのまま使えるのが利点です。Windows用と Mac用があります。

Museアプリ内で開いている場合、ダウンロードリンクを押しても保存できないことがあります。その場合は、このページをブラウザで開いてからダウンロードしてください。ダウンロードボタンは新しいタブで開きます。

Windows用

  • Windows専用です。iPhone／iPad／Mac では使えません。
  • 実行には Microsoft Edge WebView2 ランタイムが必要です（Windows 11 には標準搭載されています）。
  • 未署名の実行ファイルのため、Windows のスマートアプリコントロールやセキュリティ警告でブロックされる場合があります。その場合は警告の内容を確認のうえ、自己責任で許可してください。
